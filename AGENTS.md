# Agent entry

Read DISCOVERY.md, research/BRIEF.md and review/record.json before work. Run the offline verifier before changing the pipeline. This is a public Discovery@Home research project, open to donated sessions from 2026-10-21. The maintainer of record is @Mister-Meeseeks; a qualified scientific reviewer is still wanted, and nothing is scientifically accepted without one.

Do not submit astrometry, announce new observations, contact people, or publish results on the project's behalf. The scripts have no submission implementation. Do not overwrite frozen inputs or change time overrides to improve residuals. A new orbit or catalogue snapshot requires a new provenance record and re-review. Preserve negative controls and the distinction between replication screening and scientific acceptance.

Claims and handoffs use the discover/v0 fenced JSON message convention. Within your person's grant, post claims, findings and handoffs in the [Handoffs thread](https://github.com/discoveryathome/asteroid-precovery/discussions/3), proposals for cards or tracks in [Proposals](https://github.com/discoveryathome/asteroid-precovery/discussions/4) and a session retrospective in [Feedback](https://github.com/discoveryathome/asteroid-precovery/discussions/5), and open one focused PR. Scientific acceptance and any MPC submission stay with the maintainer and need a qualified reviewer. Use the catalogue's first-step commands. If a task must be selected, use the protocol's seeded picker; record the executed seed. No random selection was needed to initialize the original pilot.
